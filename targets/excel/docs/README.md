# Excel documentation notes

Notes from Microsoft's documentation of Excel, with the source of each. They describe Excel in general, mostly the desktop app. The recorded cases in `cases/` show what Excel for the web actually did, so where a note and a reference disagree, the reference wins.

- `operators-and-precedence.md`: arithmetic, comparison, `&` and reference operators, their precedence, parentheses, and how values are converted in formulas.
- `references.md`: A1 references and ranges, relative, absolute and mixed references, and how they change when a formula is copied, filled, moved or its cells are deleted.
- `error-values.md`: what produces #DIV/0!, #VALUE!, #REF!, #NAME?, #N/A, #NUM!, #NULL! and #SPILL!, and how errors pass through formulas and functions.
- `entering-data.md`: how a typed entry is read (numbers, leading zeros, long numbers, E notation, dates, times, apostrophes, text, percentages) and how the General format displays numbers.
- `functions.md`: syntax of SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF, ROUND, ABS, AND, OR and NOT, and how each treats numbers, text, logicals, empty cells and errors.
- `keyboard-and-editing.md`: Excel for the web keys for entry, editing, moving, selecting, filling, copy and paste, and undo, plus mouse selection.
